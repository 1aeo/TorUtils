plus tor-geoipdb (all) for each. Checksums: SHA256SUMS.

The two builds are the same code with the same features. They differ only in
the system libraries each Ubuntu release ships (24.04: OpenSSL 3.0.13,
zlib 1.3, liblzma 5.4.5, libzstd 1.5.5; 26.04: OpenSSL 3.5.5, zlib 1.3.1,
liblzma 5.8.3, libzstd 1.5.7; libevent 2.1.12 on both) and the compiler
(gcc 13.3 and gcc 15.2). Identical: configure feature summary and configure
line, the 64-entry package file list, Depends/Recommends/Suggests, and NEEDED
sonames.

Every defense is off: HSDirOneRequestPerCircuit, HSDirRefuseUnknownPrevHop and
DoSBeginDirLimitEnabled default to auto, and no consensus sets their
parameters; HSDirDescriptorFetchLimit defaults to 0. The MetricsPort series of
0006-0010, and the hardening of 0001-0005, are always active, so the build is
not equivalent to stock.
